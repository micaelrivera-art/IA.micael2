Ciência de Dados e Técnicas Integradas em IA
 
1. O que são dados de treinamento?
 
São todas as informações com as quais a inteligência artificial aprende a reconhecer padrões, fazer previsões ou responder perguntas. Podem ser textos, fotos, áudios ou números coletados do dia a dia. Quanto mais dados bons e variados tiver, melhor funciona o modelo, pois ele conhece mais situações diferentes para analisar.
 
2. Viés na inteligência artificial
 
O viés acontece quando os dados de treinamento têm erros ou ideias injustas. Por exemplo, se a IA aprender só com fotos de pessoas de um único lugar ou perfil, ela pode não reconhecer bem outras pessoas ou dar respostas injustas. Isso mostra que a IA repete o que os humanos colocam nos dados, sem ter opinião própria.
 
3. Overfitting (ajuste excessivo)
 
O overfitting ocorre quando a IA memoriza muito os dados de treinamento, como quem decora uma lição sem entender o assunto. Quando aparece uma informação nova, ela não sabe responder bem. Por isso devemos testá‑la com dados que ela nunca viu antes, para saber se realmente aprendeu.
 
4. Como funcionam os algoritmos de recomendação?
 
Eles usam dados como horário de uso, cliques e tempo de tela para mostrar conteúdos parecidos com os que já vimos. Quando só mostram coisas semelhantes ao que gostamos, se forma a chamada bolha digital: deixamos de ver assuntos novos ou pontos de vista diferentes.
 
5. Privacidade e segurança
 
As empresas devem proteger os dados dos usuários para que conversas, gostos ou informações pessoais não sejam compartilhadas sem permissão. Os guardrails são regras programadas que evitam respostas ofensivas, perigosas ou informações falsas da IA.
 
6. Futuro da inteligência artificial
 
A IA está crescendo muito e vai ajudar em várias áreas: saúde, estudos e até no trabalho. Mas precisamos usá‑la com cuidado, sempre verificando se ela é justa e segura para as pessoas.                                                                                                           
 
 7. O que acontece se o modelo não for bom?
   
Se o modelo não funcionar bem, ele pode errar de duas formas:
 
-  Pensa que é golpe, mas é verdadeiro → A família não recebe ajuda quando realmente precisa.
​
-  Pensa que é verdadeiro, mas é golpe → A pessoa envia o dinheiro e perde tudo.
 
Quando o modelo erra muito, ninguém confia mais nele e os golpes continuam acontecendo. Por isso, é fundamental que o modelo seja preciso.                                                                                       

8. Apresentação curta

  Abertura: Estão clonando vozes para aplicar golpes nas famílias. Precisamos agir agora.
 
 Problema: Ligam usando a voz de alguém da família pedindo dinheiro. Muitas pessoas caem no golpe por medo.
 
Dados: Analisamos milhares de ligações — falsas e verdadeiras. Já sabemos como esse golpe funciona.
 
 Solução: Temos uma ferramenta que descobre se a voz é falsa. Se houver risco, avisamos na hora.
 
 Próximos passos: Diga a todos: antes de enviar dinheiro, ligue de volta para um número que você já conhece. Começamos hoje mesmo.
